Recommended: use Safari for the simplest iPhone setup. Install first, then launch Prospect from the new Home Screen icon before enabling notifications.

Launch Prospect from the Home Screen iconThis opens the installed web app instead of a normal Safari tab.
Open this Install App tabTap Enable notifications and choose Allow.
Enable GPS when you want Find CrewTap Enable location here or Share my GPS in Find Crew, then allow location while using the app.
